# StudyFlow

**StudyFlow** — трекер звичок і продуктивності для студентів.

## Про проєкт

StudyFlow — це веб-застосунок, призначений для допомоги студентам в організації навчання, плануванні щоденних завдань та формуванні корисних звичок.

Застосунок поєднує планувальник завдань, трекер звичок, статистику продуктивності та систему гейміфікації.

## Основні можливості

- **Створення та редагування завдань** — користувач може додавати навчальні завдання, встановлювати їх назву, опис, пріоритет та термін виконання.
- **Трекер звичок** — користувач може створювати корисні звички та відмічати їх щоденне виконання.
- **Планування навчального дня** — застосунок дозволяє переглядати актуальні завдання та планувати навчальне навантаження.
- **Система балів і рівнів** — за виконання завдань та звичок користувач отримує бали та підвищує свій рівень.
- **Статистика прогресу** — користувач може переглядати статистику виконаних завдань та звичок.
- **Нагадування** — система може нагадувати про заплановані завдання та щоденні звички.
- **Досягнення** — користувач отримує віртуальні досягнення за виконання певних умов.
